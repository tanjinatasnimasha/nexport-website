# Nexport Tech Corporation website

This is the website source for the privately hosted Nexport prototype.

## Files
- index.html: page content and structure
- styles.css: design and responsive layouts
- model.js: bilingual service content and inquiry logic
- app.js: interactive behavior
- assets/: website illustration and favicon

## Upload to GitHub
1. Create a repository named nexport-website and choose Private.
2. Extract this ZIP on your computer.
3. Use Upload files in your repository and upload these files and the assets folder, keeping their structure.
4. Commit the changes. Uploading the ZIP alone does not make the source editable in GitHub.

## Updates
Edit the HTML, CSS or JavaScript files and commit your changes. Updates in this GitHub repository do not automatically change the current Sites-hosted website. That website requires a separate Sites deployment.

## Inquiries and privacy
The inquiry builder prepares an email draft; it does not send, store or submit inquiries automatically. Only the interface language is saved locally in the browser. The rooftop image is an AI-generated concept, not a claimed Nexport installation. Keep the repository private unless public release is explicitly approved.
